## Επόμενο βήμα

Το νέο TEST deployment επιστρέφει τα πρόσθετα πεδία. Οι κενές τιμές κρατούν ανενεργά τα αντίστοιχα κουμπιά. Δεν χρησιμοποιείται η σελίδα αλλαγής πληρώματος ως κατάλογος πληρωμάτων.

Το TEST endpoint διαβάζει τα προαιρετικά πεδία crewsUrl, resultsUrl, noticeUrl, entryFormUrl, websiteUrl, photosUrl και organizerLogoUrl. Αν το entryFormUrl είναι κενό και υπάρχει jotformFormId, σχηματίζεται ο σύνδεσμος φόρμας. Ο ιδιωτικός χώρος δημιουργίας νέου αγώνα και ρυθμίσεων θα χρειαστεί χωριστό έλεγχο πρόσβασης.
