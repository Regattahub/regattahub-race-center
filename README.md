# RegattaHub Race Center

Πακέτο για ξεχωριστό repository `Regattahub/regattahub-race-center`.

## Περιεχόμενο

- `index.html`: αρχική σελίδα Κέντρου Αγώνα.
- `styles.css`, `header.css`, `palette.css`: εμφάνιση και προσαρμογή σε κινητό.
- `app.js`: κουμπιά και δοκιμαστικές ρυθμίσεις.
- `race-config.json`: μόνιμοι τίτλοι, στοιχεία και σύνδεσμοι.
- `assets/entryflow.png`: το υπάρχον σήμα EntryFlow.

## Εγκατάσταση στο GitHub Pages

1. Δημιουργήστε ξεχωριστό repository στην οργάνωση Regattahub με όνομα `regattahub-race-center`.
2. Αποσυμπιέστε το ZIP. Ανεβάστε τα αρχεία και τον φάκελο `assets` στη ρίζα του repository. Μην ανεβάσετε μόνο το ZIP και μην ανεβάσετε τον εξωτερικό φάκελο ως υποφάκελο: το `index.html` πρέπει να βρίσκεται στη ρίζα.
3. Στις Settings → Pages ορίστε Deploy from a branch, branch `main`, folder `/ (root)` και Save, εφόσον αυτό υποστηρίζεται από τον λογαριασμό και το repository σας.
4. Χρησιμοποιήστε τον σύνδεσμο που θα δώσει το GitHub Pages μετά την επιτυχή δημοσίευση.

## Μόνιμες ρυθμίσεις

Επεξεργαστείτε το `race-config.json` στο GitHub και αποθηκεύστε την αλλαγή με commit. Ο τίτλος είναι προσωρινά γενικός, για να μη συσχετίζεται ο συνδεδεμένος viewer με λάθος όνομα ή έτος αγώνα. Η ημερομηνία είναι κενή και ο διοργανωτής ΝΟΕΦ.

Ο σύνδεσμος `links.entries` είναι ο πλήρης σύνδεσμος viewer που δόθηκε και άνοιξε επιτυχώς στην ανώνυμη περιήγηση. Οι υπόλοιποι σύνδεσμοι είναι κενoί μέχρι να οριστούν. Οι επτά επιλογές είναι ανεξάρτητες: Πίνακας συμμετοχών, Πληρώματα ανά σκάφος, Αποτελέσματα, Προκήρυξη, Δήλωση συμμετοχής, Website αγώνα, Φωτογραφίες & Video.

Τα πεδία `raceTitle`, `raceDate`, `organizer`, `organizerLogoUrl` και `links` αλλάζουν ανά αγώνα. Οι διευθύνσεις πρέπει να είναι πλήρεις HTTP/HTTPS, χωρίς ενσωματωμένα στοιχεία σύνδεσης. Το σήμα διοργανωτή είναι προαιρετικό και χρειάζεται σύνδεσμο εικόνας.

Το κουμπί «Ρυθμίσεις TEST» εξακολουθεί να εφαρμόζει αλλαγές μόνο στη μνήμη της ανοιχτής σελίδας. Δεν αποθηκεύει αλλαγές στο GitHub, στη Google ή στο Jotform. Για μόνιμες αλλαγές ενημερώνετε το JSON.

## Πρόσβαση και επόμενη ενσωμάτωση

Το πακέτο δεν περιλαμβάνει σύστημα σύνδεσης χρήστη. Αν δημοσιευτεί δημόσια, η αρχική σελίδα και οι σύνδεσμοί της είναι δημόσιοι. Τα δικαιώματα του viewer και κάθε άλλης υπηρεσίας συνεχίζουν να ελέγχονται από εκείνη την υπηρεσία. Οι συνεδρίες με πολλούς λογαριασμούς Google μπορεί να επηρεάσουν το Apps Script.

Ο υπάρχων viewer και οι φόρμες δεν τροποποιούνται. Το πακέτο δεν περιέχει κωδικούς, προσωπικά δεδομένα συμμετοχών ή ρυθμίσεις του ιδιωτικού Site. Η ενσωμάτωση στα master templates και στο New Race Wizard παραμένει επόμενο στάδιο. Αν μεταφερθεί σε repository συγκεκριμένου αγώνα όπου υπάρχει ήδη `index.html`, μετονομάστε την αρχική σελίδα σε `home.html` και ελέγξτε τις σχετικές διαδρομές πριν τη δημοσίευση.
