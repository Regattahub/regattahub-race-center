# RegattaHub Race Center — TEST Sheet v1

Έκδοση σύνδεσης μόνο με το PLATFORMA_TEST_2026_ΣΥΜΜΕΤΟΧΕΣ.

## Ανέβασμα στο GitHub

Στο repository regattahub-race-center ανεβάστε όλα τα αρχεία αυτού του φακέλου στη ρίζα, μαζί με τον φάκελο assets. Αντικαθιστούν την προηγούμενη δοκιμαστική έκδοση. Commit: Connect Race Center to TEST sheet settings.

Δεν απαιτείται αλλαγή ή νέο deployment στον υπάρχοντα Apps Script.

## Τι διαβάζεται μόνιμα από τις ΡΥΘΜΙΣΕΙΣ

| Κλειδί στο Sheet | Χρήση στο Κέντρο |
| --- | --- |
| RACE_TITLE | Τίτλος αγώνα |
| RACE_DATE | Ημερομηνία |
| ORGANIZER_NAME | Διοργανωτής |
| ORGANIZER_BANNER | Banner πάνω από τα κουμπιά |
| VIEWER | Πίνακας συμμετοχών |

Αλλάξτε τιμές στο TEST Sheet και ανανεώστε το Κέντρο. Η ανάγνωση χρησιμοποιεί το υπάρχον Β17 με callback JSONP. Η διεύθυνση και το ID περιορίζονται στον συγκεκριμένο TEST. Δεν υπάρχει εγγραφή στο Sheet από αυτό το πακέτο.

Το banner είναι διαφορετικό από το προαιρετικό σήμα διοργανωτή στην κεφαλίδα. Το assets/entryflow.png είναι το σήμα EntryFlow.

Η φόρμα «Ρυθμίσεις TEST» παραμένει προεπισκόπηση. Περιλαμβάνει σύνδεσμο προς το TEST Sheet για τις μόνιμες αλλαγές των παραπάνω πεδίων. Δεν εμφανίζει μήνυμα μόνιμης αποθήκευσης.

## Επόμενο βήμα

Το τρέχον deployment Β17, σύμφωνα με την εικόνα ελέγχου, δεν επιστρέφει ακόμη συνδέσμους για πληρώματα, αποτελέσματα, προκήρυξη, φόρμα, website και φωτογραφίες. Αυτά τα κουμπιά παραμένουν χωρίς σύνδεση. Δεν χρησιμοποιείται η σελίδα αλλαγής πληρώματος ως κατάλογος πληρωμάτων.

Έχει προβλεφθεί ανάγνωση των προαιρετικών πεδίων crewsUrl, resultsUrl, noticeUrl, entryFormUrl, websiteUrl, photosUrl και organizerLogoUrl όταν προστεθούν σε TEST endpoint. Αν το endpoint επιστρέψει jotformFormId, σχηματίζεται ο σύνδεσμος φόρμας. Η αποθήκευση από το ίδιο το Κέντρο χρειάζεται χωριστή υλοποίηση με έλεγχο πρόσβασης.

## Έλεγχος

Ελέγχθηκε η σύνταξη JavaScript και με προσομοιωμένη απάντηση η αντιστοίχιση πεδίων, η απόρριψη διαφορετικού Sheet και η αντιμετώπιση αποτυχίας φόρτωσης. Ο χρήστης επιβεβαίωσε ότι το Β17 επιστρέφει success:true με τα στοιχεία του TEST. Η φόρτωση JSONP από την πραγματική σελίδα GitHub Pages πρέπει να επιβεβαιωθεί μετά το commit.
